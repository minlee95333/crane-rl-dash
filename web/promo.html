023D REPLAY

제출하는 순간, 당신의 계획이 현장이 됩니다

플레이 중에는 정보가 균등한 2D 도면 — 제출 후에는 실제 양중 절차를 따라가는 3D 시네마틱. 보상 신호를 오염시키지 않으면서 몰입을 만듭니다.

LMI

정격하중 실시간 판독

붐이 뻗는 동안 현재 반경의 정격 대비 하중이 계산되어 붐과 반경 링이 초록 → 앰버 → 빨강으로 바뀝니다. 실제 크레인 LMI 계기판과 같은 문법.

TAIL

테일 스윙 위험 반경

상부체가 선회할 때 카운터웨이트 후미가 그리는 원을 빨강 점선으로 표시 — 현장 사망사고 1순위 위험 구역입니다.

RIG

리깅 + 진자 스윙

케이블이 훅 블록까지 내려와 4가닥 슬링으로 화물을 묶고, 이륙 직후엔 감쇠 진자처럼 흔들리다 잦아듭니다.

TELE

3단 텔레스코픽 + 처짐

붐 섹션이 실제로 슬라이드되어 뻗고, 하중이 매달리면 무게에 비례해 끝단이 휘어 내려갑니다.

PATH

이동 경로 추적

제한구역을 우회하는 실제 주행 경로가 지면에 그려지고, 지나간 step은 흐릿한 흔적으로 누적됩니다.

CAM

시네마틱 카메라

작업 중인 크레인을 따라가는 저공 추적 샷과 현장 전체 궤도 샷을 버튼 하나로 전환합니다.
